# Daggerbot

A Discord bot for rolling Daggerheart duality dice.

## ?roll

Rolls Hope (d12) and Fear (d12) and shows the result with an image.

?roll                 plain roll
?roll <modifier>      add a modifier, e.g. ?roll 2 + 3
?roll [modifier] adv  also add a d6 advantage die, e.g. ?roll +2 adv

Total = Hope + Fear + modifier + advantage
Higher die wins the outcome (Hope or Fear). Equal dice is a critical.
